# shiti-app

## 拾题 · 个人错题本

四个板块：录题、错题本、练习、设置。支持分科管理、图片旋转与框选、百度 OCR、人工校对、DeepSeek 分析与举一反三、JSON 备份和独立私有仓库同步。

默认流程：框选图片 → 百度高精度 OCR → 校对原文 → DeepSeek 文字分析。OCR 原文按行保留，不自动纠错。

### 使用与部署

网页无需构建，GitHub Pages 使用 main 分支根目录。百度代理配置见 [BAIDU-OCR.md](BAIDU-OCR.md)。AK/SK 只配置在代理端，个人题库保存在浏览器或独立私有仓库，不放入此公开代码仓库。网页中的个人密钥仅保存在当前浏览器会话。

本地运行：Node.js 22+ 执行 `node server.cjs`，打开 http://127.0.0.1:4173 。测试执行 `npm test`，无需安装运行依赖。`.env.example` 是占位示例，实际 `.env` 已忽略，请勿手动上传。

真实 OCR 和模型调用需要配置个人凭据，模拟测试不替代识别精度验收。
